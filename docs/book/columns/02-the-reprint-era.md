# 專欄 02　翻印的年代：華泰秘笈與ファミマガ

## 題旨

同一本日本雜誌《ファミリーコンピュータMagazine》，在台灣落地過兩次：1986 年華泰的
未授權翻印，1994 年尖端的授權中文版。中間隔了八年，也隔了一整套版權觀念的成形。
這篇用一組對照講完那八年。

- **只跳過一次**（通卷 31），此後穩定，節奏是月 2 回。所以「末段跟不上而逐期漏期」
  的舊說法不成立。
- **末期封面改自製**：第 27、28 期不再照搬原刊封面。
- **1994 年的另一次落地**：16《Game天堂!》是授權中文版，封面印授權字樣；
  21《Game天堂EX》改版後那行字消失了，站上因此把它另建成一本刊。

## 要注意的坑

- **翻印不是本書要評價的事**，是要記錄的事。寫法上照錄事實、不做道德判斷。
- 第 27、28 期的對應只是△（靠封面選題重疊推的），不能寫成「即該期的翻印」。
- 華泰 24 期一期都沒有出版日，任何時間敘述都要帶推定標記。
