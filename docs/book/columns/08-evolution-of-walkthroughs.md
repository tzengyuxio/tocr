# 專欄 08　攻略的形式演化：秘笈→金手指→手繪地圖→別冊

## 題旨

攻略內容在這四十年裡換過好幾種形狀：翻印日本秘笈 → 密技與修改碼（金手指）→
編輯部手繪地圖與流程圖 → 從雜誌裡分出去變成別冊。每一次換形狀，背後都是遊戲本身
變了、或是資訊的取得方式變了。

## 手上的證據

| 形態 | 代表刊 | 年代 |
| --- | --- | --- |
| 翻印秘笈 | 01 華泰任天堂秘笈（原名《任天堂程式解法大公開》） | 1986–1987 |
| 攻略專門月刊 | 17 攻略月刊（電腦玩家）、《電玩攻略》 | 1993–1995 |
| 半月刊化的攻略快報 | 18 攻略快報（革新 1–18 號） | 1996 |
| 純金手指刊 | 44 金手指補給站（TOUGH CODE SUPPLY DEPOT） | 1997–1998 |
| 攻略別冊 | 14 新遊戲時代《正宗攻略寶典》系列 | 1990 年代後期 |
| 一整套系列的總攻略 | 13 勝利小子「緊急增刊 太空戰士 I–VI 攻略特輯」（停刊號） | 1997 |

- 第一段刊名叫《任天堂程式解法大公開》——「程式解法」這個講法本身就是那個年代的
  詞彙化石。
- 44《金手指補給站》整本都是密技與修改碼，60 元、雙週刊，是攻略內容最極端的商品化。
- 別冊的出現代表攻略從「雜誌的一個單元」變成「另一個商品」，也是雜誌本體開始瘦身的
  訊號。

## 要注意的坑

- 手繪地圖那一段**目前沒有掃描證據**，站上收的是目錄不是內頁。要寫得先掃內頁。
- 別冊算不算「一期」，站上有明確判準（另立名目的不進正刊編號序列），這篇順帶可以
  把那條判準講給讀者聽。
