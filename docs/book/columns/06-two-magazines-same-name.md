# 專欄 06　兩本《攻略快報》：同名不同刊怎麼分

## 題旨

台灣遊戲雜誌史上有兩本《攻略快報》，中間隔六年、出版社不同、來歷不同。這是讀者
最容易以為「書印錯了」的地方，明寫出來反而是本書的賣點。順帶把同一類的其他撞名
案例一次收齊。

## 手上的證據

| | 18 攻略快報（尖端） | 24 疾風快報 → 攻略快報 |
| --- | --- | --- |
| 出版社 | 尖端出版 | 攻略快報雜誌社（原疾風快報雜誌社） |
| 由來 | 《電玩攻略》1996-01-20 改版 | 《疾風快報》2002-04-13 改版 |
| 期號 | 革新 1 號–18 號 | 試刊號起重編 |
| 刊期 | 半月刊（每月 5、20 日） | 週刊 |
| ISSN | 1022-4823 | 未詳 |
| 商標 | — | 疾風の狼 |

**同一類的其他撞名**：

- **Super Gamer**：04《電視遊樂報導》1999 年改版的《Super Gamer 流行電玩週刊》，
  與尖端《玩家快訊》1995 年改名的《超級玩家（Super Gamer）》——撞的是完整並列刊名，
  比《攻略快報》更容易誤併。（後者站上還沒收）
- **勝利小子／勝利少年**：13（1993、尖端、V.V. KIDS）與 23（1997）只差一個字。
- **攻略月刊／電玩攻略月刊**：17（1994、電腦玩家雜誌社）與電玩政略月刊社那本。
- **次世代**：27《次世代遊戲情報》的出版社是協和國際多媒體，30《電玩百分百週刊》的
  出版社才叫「次世代」。

## 圖版

- 兩本《攻略快報》的封面並置，各標出版社與年份（本篇主圖，也是全書辨異框的範本）
- 辨異框的版式草案：紅底、雙欄、固定放在該刊資料卡右側

## 要注意的坑

- **以出版者與期號序列認人，不以刊名認人**——這條原則要在這裡講明白，後面幾組撞名
  才有依據。
- 尖端那本的前身《電玩攻略》整條刊系站上還沒建，寫的時候不要把它當已確認的收錄。

## 待查

- 尖端《玩家快訊》／《超級玩家》整條刊系（站上完全沒有）
- 電玩政略月刊社《電玩攻略月刊》（1993-11 創刊、28 期）的實物
