## 目錄

### magazines/　圖鑑主體 56 篇

檔名前綴＝**年代序**（依創刊日排，年代未詳的排最後），與書上的順序一致。
**新增一本刊會讓它後面的編號整批位移**，所以引用某一篇時認 slug 不認編號。
frontmatter 的 `tier` 是頁數分級：

- **A（4–6 頁，11 本）**：已知或已建期數破百——03 電視遊樂雜誌、04 電視遊樂報導、
  06 軟體世界、09 電腦玩家、10 電腦遊戲世界、14 新遊戲時代、33 飛訊電玩周刊、
  40 電玩e世代、41 電玩通PS2、47 電玩通、49 電玩双週刊。
  （book.md 原本估 9 本，是資料補進來之前的數。要不要都給 4–6 頁由編排時決定）
- **B（2–3 頁，16 本）**：中刊
- **C（1 頁或兩本共頁，29 本）**：短命刊

每一篇的固定結構：資料卡／收錄狀況／定價變遷／封面資訊／逐期附註／全期一覽（30 期
以內才有）／**沿革**／**可寫的話題**／圖版候選／資料缺口／出處。
前半是機器從站上產的，後半（沿革、話題、出處）是人整理的。

## 動筆前一定要知道的三件事

1. **「收錄 N 期」不是「出過 N 期」。** 每一份的資料卡都分開寫「已知總期數」與
   「站上已建」，兩者差距大的刊（26 疾風快報 9／210＋、34 新世紀 HYPER PlayStation
   60 期只有 1 張封面）不要寫成完整敘述。
2. **56 本裡 41 本沒有停刊日**（另 2 本仍在發行，空值正確），6 本連創刊日都沒有。甘特圖上是開放線段，正文裡不要寫
   「出到某年停刊」，要寫「已知最後一期是⋯⋯」；創刊日未詳的六本排在年代序最後，
   位置本身就是待考。
3. **可信度標記要一路帶到底**：◉ 實物／○ 文獻／△ 待考。每一篇的〈出處〉那節都已經
   標好了，正文直接沿用。

## 快照怎麼重跑

腳本在 [`_scripts/`](_scripts/)，全部走公開 API，不需要憑證。跑法與各檔的分工見
[`_scripts/README.md`](_scripts/README.md)。

`gen.mjs` **會依 slug 把既有那份稿的〈沿革〉〈可寫的話題〉〈出處〉三節原樣搬過來**，
其餘全部重產；編號前綴依創刊日重算，舊檔名會一併刪掉。所以重跑之後要做的只有兩件事：
新增的刊要補寫那三節，以及回頭對一次本檔與 `front-matter/`、`appendix/` 裡的數字。
