## 動筆前一定要知道的三件事

1. **「收錄 N 期」不是「出過 N 期」。** 每一份的資料卡都分開寫「已知總期數」與
   「站上已建」，兩者差距大的刊（24 疾風快報 9／210＋、32 新世紀 HYPER PlayStation
   60 期只有 1 張封面）不要寫成完整敘述。
2. **44 本裡 31 本沒有停刊日。** 甘特圖上是開放線段，正文裡不要寫「出到某年停刊」，
   要寫「已知最後一期是⋯⋯」。
3. **可信度標記要一路帶到底**：◉ 實物／○ 文獻／△ 待考。每一篇的〈出處〉那節都已經
   標好了，正文直接沿用。

## 快照怎麼重跑

資料全部來自公開 API，不需要憑證：

```
GET https://tocr.simagame.me/api/magazines?limit=100
GET https://tocr.simagame.me/api/issues?magazineId=<id>&limit=100&page=N   # limit 上限 100，要分頁
```

產生器在 session 的 scratchpad（`gen.js` 產資料卡與收錄狀況、`gen-appendix.js` 產附錄、
`fill*.js` 是人寫的沿革／話題／出處）。重跑時**只重產機器的那半**，
`fill*.js` 的內容要保留。
