## 可寫的話題

1. **寫這批雜誌的雜誌**：本刊本身就是懷舊刊物，題材與本書重疊。書該怎麼寫它——是同業、是史料、還是這本書的前輩——需要一個明確的態度。

2. **2017 年還有人做紙本**：距離《電腦玩家》停刊八年。紙本回潮與同人／募資出版的關係，是這批 44 本裡唯一屬於當代出版生態的案例。

3. **封面不標日期**：NO.5 之後連年月都不印。這對編目是災難（30 期全無出版日），對本書卻是好題目——雜誌什麼時候開始覺得「哪一期」比「哪一天」重要。

4. **30 期全有封面**：圖版滿分，可以排一整條當代封面帶，與 1980 年代那條對照。
