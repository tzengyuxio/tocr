## 沿革

- **1987-07-05** 以《電視遊樂快訊》之名出試刊號（尖端）。前一個月《華泰任天堂秘笈》第 28 期出刊，兩者的交接是本書開頭的關鍵接點。
- **第 2 期起** 改名《電視遊樂雜誌》（站上第二段刊名時期）。半月刊。
- **1988-09 至 11** 第 28–33 期一段的封面與發行日，站上曾整段錯掛一期，2026-09-05 依封面實印的期號與出刊日校正。
- **1998 春節** 與《電視遊樂報導》合出《1998電玩 電視遊樂報導 電視遊樂雜誌 新春合併號》，兩本的期數序列各少一期（該期建在報導底下）。
- **1999-08-05** 改版為《GAME fans 遊戲專家》，期號另標「新刊 N 號」，通卷續為 293–300（藏家清單）。
- **1999-12-05** 新刊 5 號（通卷 297）為站上最後一期；其版權頁預告「下期元月 5 日登場」，故應有新刊 6 號（通卷 298、2000-01-05），實物未見。已知總期數記 301。

## 可寫的話題

1. **刊頭上方那行自我定位，就是台灣主機市場的縮影**：PC-Engine → 電視遊樂 → 超級任天堂 → SFC＋MD → SS＋N64 → SEGA SATURN，一本刊十二年換六種說法。這條線單獨拉出來做一個跨頁的圖表，是本書最強的一張圖之一。

2. **「全國第一本」的宣稱**：同一時期尖端的兩本刊都印「全國第一本」，各自宣稱的類別不同。廣告語與市場定位的關係，可以與《電視遊樂報導》對照著寫。

3. **改名三次卻是同一條刊系**：快訊 → 電視遊樂雜誌 → GAME fans。期號在最後一段重編為「新刊 N 號」，通卷仍在跑，這正是刊名索引要把三個名字導到同一頁的理由。

4. **封面錯掛一整段的訂正**：站上曾把 28–33 期的封面與日期整段錯掛一期，靠封面右上角實印的期號與出刊日校正。這是〈本書的考據原則〉現成的案例——錯的資料看起來就是「已經有了」。

5. **與《電視遊樂報導》的 1998 新春合刊**：全站唯一一次兩本刊合出一冊，兩邊期數各少一期。同一集團兩本刊的關係，可以順著談尖端的雙刊布局。

6. **300 期裡 239 期有發行日、86 期有封面**：長壽刊的收錄密度不均本身值得畫成一條「已知度」曲線，也是缺期徵集清單的主要來源。
