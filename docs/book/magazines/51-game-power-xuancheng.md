## 可寫的話題

1. **以「輯」計數、以節氣命名**：不標年月、標「驚蟄特刊」。這種計數方式讓後人排不進年表，卻是當年書報攤刊物常見的做法——期號與時間的關係，全書有好幾個這類案例可以並置。

2. **撞名的兩本 GAME POWER**：與創造出版的《創造遊戲百科》封面拉丁刊名相同，站上只好各以出版社當 slug 的區別段。同名不同刊的第三個案例（另兩個是兩本《攻略快報》與兩個 Super Gamer）。

3. **附光碟的電子雜誌專欄**：光碟裡放「GP＿電子雜誌」——紙本刊在光碟上再辦一份電子版，是 1990 年代末的過渡形態。
