## 可寫的話題

1. **高雄出的雜誌**：這批刊絕大多數在台北，本刊是少數的例外，值得在出版社譜系圖上標出地點。

2. **只有兩期的刊怎麼進圖鑑**：一頁裡放兩張封面、一份完整目錄，短命刊反而能做到「全刊呈現」——頁數不均本身就是資訊，這一本是最好的示範。

3. **代理商刊物**：內容有相當比重是自家代理產品的介紹，與《精訊電腦》《軟體之星》同型但更極端。廣告與內容的界線在哪，這一本最好談。

4. **「只出了兩期」的來源是站長口述**：可信度標記在這裡會落在 △，而不是把口述寫成史實。
