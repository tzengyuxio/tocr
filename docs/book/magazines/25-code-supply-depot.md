## 沿革

- **創刊日未詳。** 藏家清單另記一本《金手指行家補給站》1997-07-10 NO.1，是否同一條刊系待查。
- **1998-01-15** 站上最早一期（第 11 期）。雙週刊，60 元，並列刊名 TOUGH CODE SUPPLY DEPOT。出版者泰源雜誌社。
- **1998-10-28** 第 30 期（站上最晚一期是第 31 期）。站上 27 期，9 期有封面，全部有出版日。

## 可寫的話題

1. **唯一一本純金手指刊**：不做評測、不做新聞，整本都是密技與修改碼。〈攻略的形式演化：秘笈→金手指→手繪地圖→別冊〉那篇專欄的主角，本書給它一頁剛好。

2. **從書末搬回年代軸上**：上一份快照時它是全站唯一沒有創刊年的刊，只能擺在書末；2026-09 補上 1997-08-28 之後，它回到年代序的第 24 位。資料一補，版式就得跟著改——這件事值得在編輯後記裡講一句。

3. **與《金手指行家補給站》的關係**：名字只差兩個字，1997 年的 NO.1 與本刊 1998 年的第 11 期能不能接上，只要一期實物就能定案。徵集清單上要點名第 1–10 期。

4. **60 元的雙週刊**：定價全期不變，薄而便宜，是攻略型刊物的典型規格。
