## 沿革

- **1994-07-21** 創刊（尖端），雙週刊，日本《ファミリーコンピュータMagazine》授權中文版，並列刊名 GAME PARADISE MAGAZINE。
- 出刊節奏逐段變慢：創刊號→No.5 平均 13.8 天、No.5→No.23 平均 14.9 天、No.23→No.36 平均 17.2 天。
- **1996-01-19** No.36。藏家清單記 **1997-01-17** 休刊、共 64 期，但依前段的節奏，1996-01 到 1997-01 只放得下約 21 期（末期落在 No.57 附近）——**期數與休刊日至少有一項不對**。
- **1997-02-17** 改版為《Game天堂EX》（另建一本，見 21）。

## 可寫的話題

1. **期數對不上的一本**：節奏算出來的末期在 No.57 附近，藏家清單說 64 期。三種可能（期數不對、休刊日更晚、後段改回雙週）只要一期實物就能分辨。這是可信度標記從 ○ 降到 △ 的教科書案例。

2. **兩本ファミマガ中文版**：華泰的翻印（1986）與尖端的授權版（1994），中間隔八年。同一本日本雜誌在台灣的兩種落地方式，是〈翻印的年代〉那篇專欄的主線。

3. **節奏會變慢**：雙週刊拖到 17 天一期，往往是停刊的前兆。把這條與《電玩族》《SG遊戲週刊》放在一起，可以做「週刊為什麼死得最快」的量化證據。

4. **「Game天堂!」到底是不是刊名**：那個驚嘆號是刊頭美術還是刊物自印的並列刊名，決定站上的 slug 要怎麼取，至今未定。這件事本身很適合寫進〈本書的考據原則〉。
