## 可寫的話題

1. **青文的電擊四本**：電擊PlayStation、電擊SEGA SATURN、電擊王／DengekiGAMES，加上未定的電擊Dreamcast。同一家出版社把日本 Media Works 一整個雜誌家族搬進台灣，是出版社譜系圖上最壯觀的一塊。

2. **封面上印錯的日期**：休刊號封面誤印 2001/9/12。印刷錯誤怎麼記——照錄封面還是記正確值——是資料慣例的問題，也是可信度標記的用武之地。

3. **PS 陣營活最久**：SS 版九個月、DC 版兩年、PS 版三年。三本並排的存續長度，直接反映主機在台灣的市佔。這張圖比任何論述都清楚。

4. **期號從「創刊 N 號」改成 VOL.**：同一本刊中途換編號系統，站上照封面錄入。期號凡例又一例。
