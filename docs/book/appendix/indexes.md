# 三個索引的資料狀況

書末三個索引：**刊名索引**、**出版社索引**、**遊戲名索引**。前兩個現在就做得出來，
第三個做不做得成取決於目錄資料，這頁把三者的現況與缺口寫清楚。

## 一、刊名索引（可以做）

規則：**所有曾用名與俗稱都導到同一頁**。要收進索引的字串有五類，站上都有欄位：

| 類別 | 站上欄位 | 例 |
| --- | --- | --- |
| 正題名 | `Magazine.name` | 電視遊樂雜誌 |
| 各時期刊名 | `MagazineTitle.title` | 電視遊樂快訊、GAME fans |
| 並列刊名 | `nameParallel` | TV GAME MAGAZINE |
| 各時期並列刊名 | `MagazineTitle.titleParallel` | onlinegame biweekly、GAMEXPRESS |
| 別名、俗稱、拼寫變體 | `aliases` | 法米通、電擊PS、SWM |

**改過名的刊系**（索引必須全部導引）：

- 01 華泰任天堂秘笈：任天堂程式解法大公開（5–6 期）→ 華泰任天堂秘笈（7 期起）
- 03 電視遊樂雜誌：電視遊樂快訊（試刊號）→ 電視遊樂雜誌（第 2 期起）→ GAME fans（新刊 1 號起）
- 04 電視遊樂報導：電視遊樂情報（情報 NO.1–18）→ 電視遊樂報導（第 1 期起）→ Super Gamer（切點未定）
- 10 電腦遊戲世界：電腦遊戲世界（85–162）→ 遊戲世界（163–242）
- 24 疾風快報：疾風快報 → 攻略快報（2002-04-13 起）
- 35 電擊王：電擊王 → DengekiGAMES（2003-02 起）
- 37 電玩通PS2：電玩通PS2（1–102）→ 電玩通PLAYSTATION +（103–115）→ 電玩通PSP+PS3（116–132）
- 42 電玩双週刊：電玩双週刊 → 電玩宅速配（vol.01 起）
- 22 電玩向前走：電玩GOGO（試刊）→ 電玩GOAL!GOAL!（創刊）／版權頁作電玩向前走月刊

**必須加辨異的同名／近名組**（索引與正文都要處理）：

- 攻略快報 ×2（18 尖端 1996／24 疾風 2002）
- Super Gamer ×2（04 電視遊樂報導改版／尖端《玩家快訊》改名，後者站上未收）
- 勝利小子（13）／勝利少年（23）
- 攻略月刊（17，電腦玩家）／電玩攻略月刊（電玩政略月刊社，站上未收）
- 「次世代」：27 次世代遊戲情報的出版社是協和；30 電玩百分百週刊的出版社才叫次世代
- 遊戲天堂／Game天堂!／Game天堂EX（16、21）——第三種寫法「遊戲天堂EX」出自維基

## 二、出版社索引（可以做）

資料在 [publisher-lineage.md](publisher-lineage.md)。兩件要注意：

- 站上的 `publisher` 是**創刊值**，中途轉手的（34 電遊人：華彩軟體 → 富利恒）
  索引要兩邊都收。
- 同一家公司的寫法不統一（「尖端」「尖端出版」並存），排索引前要先歸一。

## 三、遊戲名索引（**目前做不成完整版**）

這是別人抄不走的部分，也是最缺資料的部分。

**現況**：目錄文章 10526 篇、遊戲條目 5855 款，但**分布極不平均**：

| 刊 | 文章數 | 佔比 |
| --- | --: | --: |
| 06 軟體世界 | 9806 | 93.2% |
| 09 電腦玩家 | 416 | 4.0% |
| 03 電視遊樂雜誌 | 88 | 0.8% |
| 05 星際遊樂雜誌 | 82 | 0.8% |
| 07 軟體之星 | 78 | 0.7% |
| 13 勝利小子 | 21 | 0.2% |
| 14 新遊戲時代 | 21 | 0.2% |
| 12 立東軟體 | 14 | 0.1% |
| 其餘 36 本 | 0 | 0% |

**所以現在做出來的「遊戲名索引」等於「軟體世界索引」**，而且完全偏向 PC 與線上遊戲。

跨刊出現最多的遊戲（依文章數）：百戰天龍 48、三國演義ONLINE 40、仙境傳說 29、
金庸群俠傳ONLINE 29、新天上碑 26、創世紀VI 25、水滸傳 21、吞食天地ONLINE 19、
銀河飛將 19、石器時代 18——**全是 PC 與線上遊戲**，沒有一款家用主機遊戲。

**三個選項**：

1. **照現況做，但改名字**——叫「軟體世界遊戲索引」或「PC 遊戲索引」，並在頁首說明
   涵蓋範圍。誠實，且立刻可用。
2. **先補家用機刊的目錄**：03《電視遊樂雜誌》、04《電視遊樂報導》各補 20–30 期，
   索引才有兩條腿。這是本書最值得投入的前置工作。
3. **縮小成「封面遊戲索引」**：站上 219 期已錄入 `coverGames`，涵蓋的刊種比目錄廣，
   而且「某款遊戲上過哪幾本刊的封面」本身就是好題目。**這個現在就做得出來。**

**建議：先做 3（封面遊戲索引），把 1 當備案，2 列為續版目標。**
