# `/games/<game>` 與 `/tags/<tag>` 的表格要對齊，並重想欄位與排序

兩頁列的是同一種東西——「這個遊戲／標籤出現在哪些文章」——表格結構卻不一樣。
先對齊，再一起想清楚欄位順序與排序。

## 一、兩頁的現況差異（要收斂成同一套）

| | `/games/<game>` | `/tags/<tag>` |
| --- | --- | --- |
| 出處欄 | 「刊期」一欄 | 「雜誌」「單期」兩欄 |
| 頁碼 | 有 | 無 |

哪一種對，要一起決定：拆成兩欄在雜誌名重複時比較吵，但可各自排序；併成一欄省地方，
卻把兩個維度綁在一起。**頁碼兩頁都該有**——沒有它就少了「翻到哪一頁」這個定位資訊。

## 二、欄位順序

現在的順序是既有的，沒有特別設計過。要決定的是**頁碼放哪**：

- **提前**，跟刊期並排——讀者拿著實體雜誌找過來，「哪一期第幾頁」是一組動作，放一起最好定位
- **留在最後**——頁碼資訊量最小，前面留給標題與出處

兩種都說得通，挑一種寫進 ui-conventions 就好，重點是兩頁一致。

## 三、排序

現在沒有排序。至少兩種有意義：

- **刊期序**（同一本刊由舊到新，跨刊時要先決定刊怎麼排）
- **出版日期序**（跨刊比較才有意義，也是唯一能把不同刊放在同一條時間軸上的排法）

作法上，**點標題欄排序**比另外做下拉選單省事，也符合表格的既有直覺。
注意 `publishDate` 可空、且精度不一（年／季／月／日），排序要用 `publishSort`，
空值一律墊底——這條在 `data-conventions.md` 已經定過。

## 四、滑鼠移過刊期時顯示封面

hover 出封面縮圖，對「我記得那個封面」的讀者是最快的辨認方式。

要注意的：封面可空（站上仍有大量期數沒有封面），要有不閃版面的預留；
觸控裝置沒有 hover，得決定是改成點擊或直接不顯示。
