# 《軟體世界》201 期目錄掃描接上站之後的待辦

`~/Downloads/CC_TOC` 是《軟體世界》全 201 期的目錄頁掃描（377 張 JPG，多數每期
2 張，164–174 共 11 期是 3 張），資料夾與站上的 201 期一對一對得上
（`000`→試刊號、`001`→創刊號、`070+071`→站上的 `70+71`）。

2026-09-06 整批上傳並辨識：批次前站上只有 45 期有 `tocImages`（試刊號、創刊號、
3–43、48、49），且那 45 期的張數與本機資料夾完全一致——也就是站上那批本來就
出自同一份掃描。腳本走 `/api/upload`（folder `issues/toc`）→ `PUT /api/issues/:id`
寫 `tocImages` → `POST /api/ocr` → `POST /api/articles/batch`，全程走 API，
`edit_logs` 掛在司書(NPC) 名下。

**結果：201 期全部有 `tocImages`，200 期有文章，共 9806 篇**，只有第 72 期辨識不出來
（見下）。164–174 那 11 期是 3 張圖，開逐張辨識再合併（`PER_IMAGE`），各期落在
47–87 篇，比一次送三張的結果密實——BACKLOG 那條「三張就開始成段掉東西」在這裡
得到佐證。

**所有期的 `tocReviewedAt` 都是空的**——腳本走 token，本來就標不了複查，
未複查的期查得出來。下面是複查時要優先看的幾期。

## 第 72 期辨識不出來，模型跑掉了

`ZShTCqHy`，1995 年 3 月號。圖已在站上，文章 0 篇。連跑四次全部 422，
JSON 都斷在 42–45K 字元；**逐張辨識也一樣爆**，所以不是
[BACKLOG](../../BACKLOG.md) 那條「多張圖擠爆輸出預算」的問題。

撈 `rawText` 才看清楚是重複輸出：同一條「遊戲世界」一直複製，`pageStart`
假造到 780、784、786（那期沒這麼多頁），`subtitle` 抄的是版面上的藥品廣告詞
（「強心利膽，健胃益腸」「色香味美，利肺解脾」）。

正式站只掛得到 `openai` 這一個 provider（自架的 qwen-tw，見
[docs/deployment.md](../deployment.md)），換模型這條在站上走不通。
要嘛在後台手動辨識，要嘛等 provider 多一個。

## 第 47 期的 28 篇是舊資料

`Or_RjaEQ`。批次時 OCR 同樣回 422（JSON 解析失敗），但它原本就有 28 篇文章，
腳本刻意不覆蓋（見下），所以站上那 28 篇是這次批次之前的東西。圖已補上，
複查時值得重跑一次辨識再比對。

## 第 58 期把欄目名當成文章標題

`kA6-TNVq`。35 篇裡 17 列是重複的欄目名——`6× NEW FILES`、`5× 新GAME俱樂部`，
頁碼各不相同。這不是重複條目而是那期的目錄版式模型沒吃準，要重跑或人工修。

## 三筆同標題同頁碼的重複條目

掃過全刊之後，同標題多列的有 26 期、合計多出 69 列，但**絕大多數不是重複**：
頁碼各不相同，那是同一款遊戲在「新片預告」「評測」「攻略」各占一條，
是雜誌目錄本來的樣子。

同標題**又同頁碼**的只有三筆，這才可疑：

| 期 | | |
|---|---|---|
| 14 | 2× 熱血高校 | p50 |
| 39 | 2× 艾薇拉 II － 恐怖劇場完全攻略（上） | p74 |
| 46 | 2× 超人戰紀 | 兩筆都沒頁碼 |

都是單筆多出來的，不像整份疊加，比較像同一次辨識裡模型讀了兩遍。

## 腳本行為，重跑前要知道的

一次性腳本，冪等，進度寫 `state.jsonl`。三條規則是踩過坑之後加的：

- **`/api/upload` 的 folder 必須是 `issues/toc`**，才會套 TOC policy（2400px／JPEG）。
  寫成 `toc` 會落成 WebP，而自架的 OCR 後端解不開 WebP，直接回 500。
  第 51 期因此在 blob 留了 2 個 WebP 孤兒檔，`scripts/find-orphan-blobs.ts` 會掃到
- **已有文章、只缺圖的期只補圖不辨識**。`POST /api/articles/batch` 帶
  `replaceExisting` 會把整份目錄刪掉換成這次的結果，而手邊的掃描不保證比原本
  那份完整——第 2 期就是這樣從 74 篇變成 35 篇的（後來確認 35 接近實際的 39 條，
  原本的 74 是同一期辨識跑了兩次以上疊出來的，那次沒有損失，但規則留著）
- **有圖沒文章的期只重跑辨識，不重傳圖**
