# 《電擊Dreamcast》要建成獨立刊還是《電擊SEGA SATURN》的後續刊名時期

2026-08-23 曾建過一筆獨立的 `dengeki-dc-tw`，同日撤除，等實體本再定（2026-08-23）。

**已知事實**（來源：藏家清單 `data/collectors-note.txt`）：《電擊SEGA SATURN》1998.2.20 試刊、
1998.9.11 創刊（封面 1998/10/2）、1998.11.20 休刊（封面 **1998/12/11**），試刊 1～12 號、
創刊 1～5 號共 17 本。《電擊Dreamcast》**1998.12.11** 創刊（封面 1998/12/25）、
2000.10.27 休刊（封面 2000/11/24），創刊 1～6 號、VOL.7～38 雙週刊，VOL.39～41 改月刊，共 42 本。
日本原刊確實是《電撃セガサターン》Vol.31 之後改名《電撃Dreamcast》
（[ja.wikipedia](https://ja.wikipedia.org/wiki/%E9%9B%BB%E6%92%83Dreamcast)）。

**GNN 2000-12-11 的報導**（[gnn.gamer.com.tw/detail.php?sn=92](https://gnn.gamer.com.tw/detail.php?sn=92)）
補了三件事：台灣版《電擊Dreamcast》確由**青文出版社**發行、於 2000 年 11 月停刊（與藏家清單的
休刊日對得上）；日本原刊最後一期是 2000-12-08 出的 Vol.45，**該期收錄「由『電擊SEGA SATURN』
時代至『電擊Dreamcast』的歷代編輯的編輯手札」**；台版停刊後「轉由新出版的綜合電玩月刊
《電擊王》接手」。

那份編輯手札是**日本原刊**的判準 4（自我宣告）——母刊自己把 SS 時代與 DC 時代當成同一條連續
的編輯脈絡。台版跟著母刊改名的可能性因此更高，但這仍是對母刊的證據，**台版自己的宣告還是沒有**。

**報導裡的「接手」是業務與讀者的承接，不是刊系關係**（yuxio 2026-08-23）。日本《電撃王》
1993 年 2 月號就已創刊（月刊，メディアワークス，
[ja.wikipedia](https://ja.wikipedia.org/wiki/%E9%9B%BB%E6%92%83%E7%8E%8B)），與電撃PS／SS／DC
是各自獨立的姊妹誌，不是改名也不是衍生；台版《電擊王》2000-12 創刊，比原刊晚七年多，是另一樁
授權引進。兩本刊之間沒有刊系關係，`MagazineTitle` 不涉及此事，要記就記進
`Magazine.description`。

**依歸併判準傾向「同一條刊系」，但還缺最關鍵的那份證據。** 判準 3（出版無實質中斷）成立得
很漂亮——SS 末期封面 1998/12/11、DC 創刊號就在 1998.12.11 出而封面標 1998/12/25，正好接上
雙週刊的下一個出版週期，中間沒有空窗；判準 2（出版社相同）成立。反向判準的「期號重起＋出版
中斷＋團隊更迭」只成立一項（期號從創刊 1 號重起），照《電玩双週刊》那條的推法就該併。
但判準 1（期號序列延續）是**反的**，而判準 4（自我宣告）完全沒有資料——這正是差別所在：
《電玩双週刊》那組的連續性可以從發行節奏獨立驗證，這組只能靠版權頁或編者話說死。

**要查什麼**：DC 創刊號的版權頁（ISSN 與《電擊SEGA SATURN》是否同號——注意 ISSN 不列入
證據，但不同號可以反證）、編者話或封面有無「原《電擊SEGA SATURN》」之類的宣告、
以及編輯團隊有沒有換。查到之後二擇一：併進 `dengeki-ss-tw` 建 `MagazineTitle` 兩段，
或另建一筆 `dengeki-dc-tw`（slug 已定，yuxio 2026-08-23）。
