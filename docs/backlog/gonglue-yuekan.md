# 《攻略月刊》：刊頭與五期已補，其餘期數待查

`gonglue-yuekan` 已於 2026-08-30 建到正式站。

**同日補上刊頭與五期**：刊頭取第 4 期封面（`derived/logos/gonglue-yuekan.jpg`）；
期數建了 3、4、5、6、9（`order` 用期號減一，日後補 7、8 期不必 reorder），各帶封面圖與
定價 100，日期取封面上緣印的「1994年11月號」等。手邊掃描檔只有這五期的 c1／c4，
**c4（封底）沒有欄位可放**（Issue 只有 `coverImage` 與 `tocImages`），先留在 `covers/raw/`。
yuxio 手上有兩本實體（2026-08-25）。

**2026-08-30 從實體補到的**：創刊 1994-09-01（版權頁）、分類 PC_GAME、發行所取版權頁的
「電腦玩家雜誌社」（回函卡另作「攻略月刊雜誌社」，兩種寫法都記進 description）。
翻遍手邊兩本的封面／目錄／版權頁**都沒有正式英文名**，所以 slug 走規則 3 這件事有實物支持了。

**已知事實**：yuxio 查到目前見過的最大期數是**第 9 期（1995 年 5 月號）**。
zh.wikipedia〈電腦玩家〉原文「電腦玩家曾經發行兩版月刊型態的刊物，但是持續時間並不長」，
底下列《攻略月刊》與《光碟世界》（兩條都是紅連結）。**國家圖書館期刊指南查不到它**
——以出版單位「電腦玩家」查只回《電腦玩家雜誌》一筆，以刊名「攻略」全掃七筆也沒有它。
沒有獨立的期刊登記，與「月刊型態的刊物」相符，比較像附屬刊而非另行登記的期刊。

**正題名取《攻略月刊》，不取「電腦玩家攻略月刊」。** 後者是為了消歧義接出來的描述性組合，
刊物沒有這樣印過——這正是 slug 規範一路在防的「編輯自造」。出版者記「電腦玩家雜誌社」，
靠它分辨這本與電玩政略月刊社的《電玩攻略月刊》（1993-11 創刊、28 期、接《攻略快報》），
**以出版者與期號序列認人，不以刊名認人**（見 data-conventions 的「去重不得單看題名相似度」）。

**slug 提案 `gonglue-yuekan`。** 無並列刊名、非外刊中文版，走規則 3 拼音；機械輸出是
`gonglue`（「月刊」在可丟棄體裁尾綴的封閉清單裡，ü 一律寫 u），但這裡要套用**「體裁尾綴
變成唯一區別時不丟」**那條例外——「攻略」單獨拿出來是類別詞不是刊名，形狀與
《電視遊樂雜誌》→`tvgame-magazine` 完全相同。副作用是避開了 `gonglue` 這個過於通用的值。
電玩政略月刊社那本自己走規則 3 會是 `dianwan-gonglue`，兩者不衝突。

**封面主標印的是「攻略月刊」**——五期封面一致：上緣黃底一條放「電腦玩家」品牌小字（含 ACE 標），
與紅色主標「攻略月刊」分開兩帶，形狀確如《電玩向前走》封面的「電玩」，正題名的判斷不變。

**待查**：創刊與停刊時間；總期數。維基百科不可當來源，
這本目前沒有任何可引用的出處。同批未建的還有《光碟世界》（電腦玩家的另一本月刊型刊物）
與《網路遊戲雙週》（電腦家庭，見國圖 `journalId=69101036`）。
