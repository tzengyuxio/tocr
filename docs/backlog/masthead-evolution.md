# 刊頭標準字的演變沒有落點

長壽刊會改標準字：《軟體世界》十五年間至少十款（100 期起「界」字上半化成一顆頭、105 聖誕老人、106 包青天、127 棒球，128 期起字體由圓潤改直板、148 又轉圓潤），《電腦玩家》推測也有。已經掃好的十張在 `~/Downloads/swm_logos/`（檔名帶期號）。

**站上目前只留一張**（`Magazine.logoImage`，識別用），演變沒有存的地方。討論過三種形狀都不成立（2026-08-18）：

- **帶 caption 的清單**（Json 或關聯表）：caption 絕大多數是空的，而真正要記的「哪一期」是關聯不是文字，等於逼編輯打字換一個查不了的字串
- **掛到單期 `Issue.mastheadImage`**：期底下已經有完整封面，再存一張從它裁下來的圖是多的；而且要記的是**標準字的演變**（屬於刊物），不是「這期是聖誕老人」那種單期裝飾
- **純字串陣列**：排得出順序但講不出年代，而年代正是這批圖的意義

真要做的話，值得做成**單期刊頭的時間軸**——「界」字隨當期主題變成聖誕老人、包青天、棒球，那是這個站對懷舊讀者少見的價值。但那是展示功能的規劃，不是加個欄位就好，**動手前要先想清楚展示形狀**（2026-08-18）

**2026-08-30 縮小了範圍**：**跨刊名時期**的那一半已經有落點——`MagazineTitle.logoImage` 加上刊系頁的多刊頭 gallery（PR #130），改過名的刊每個時期一張、依時期排序、可左右切換。這一項剩下的是**同一個刊名時期之內**的演變，也就是軟體世界那十款「界」字，那仍然沒有地方放，判斷不變

**2026-08-31 補一句**：同日新增的 `Photo`（額外圖片，掛雜誌或掛單期）**不是這一項的落點**。
它裝的是來源不是本站的圖與藏書照；標準字的演變仍然缺一個講得出年代、又不必逼編輯打
caption 的形狀，上面三種被否決的理由不變。
