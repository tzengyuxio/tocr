# 《遊戲設計大師》辨識落地的副產物

2026-09-20 把 21 期的目錄頁掃描圖掛上並辨識，451 篇文章連同標籤與遊戲一次落地
（`scripts/upload-toc-scans.ts` 與 `scripts/land-ocr-articles.ts`）。這兩份是**那一輪
新建出來的**標籤與遊戲，留著是為了事後清——辨識會認錯字，而認錯的名字一旦進了
`games`／`tags`，下一期再寫一次就又多一列。

`new-games.csv` 的 `possible_duplicates` 是**用名稱前段機械比對**出來的，不是判斷：
去掉尾端的集數與版本後，前段相同的既有遊戲都列進來。所以它會列出真正的同一款
（`惡靈古堡III` 之於 `惡靈古堡 3`），也會列出只是同系列的（`Unreal Tournament`
之於 `Unreal`）。**要合併哪些是人的事**，走 `POST /api/games/[id]/merge`。

比對不到的那一類要自己看：`鹿鼎計 2` 的「計」是「記」的誤認，前段不同所以配不上
`鹿鼎記 2`；`異剛 Shogo` 應該是《昇剛》；`特攻突擊隊Ranger` 是標題被截斷。
